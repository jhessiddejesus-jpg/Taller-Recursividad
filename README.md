# Taller de Recursividad

Proyecto desarrollado en Java enfocado en la implementación y resolución de problemas mediante algoritmos recursivos.

## Estructura del Repositorio

```text
Taller-Recursividad/
│
├── src/
│   └── Recursividad/
│       
├── .gitignore
├── LICENSE
└── README.md
```

## Requisitos del Repositorio

- **Entorno de desarrollo:** Java Development Kit (JDK 17 o superior recomendado).
- **Control de versiones:** Git.
- **Estructura organizada:**
  - Código fuente ubicado en `src/Recursividad/`.
  - Documentación de requerimientos y uso en `README.md`.

## Compilación y Ejecución

Para compilar y ejecutar el proyecto desde la terminal en el directorio raíz (`Taller-Recursividad`):

1. **Compilar los archivos Java:**
   ```bash
   javac -d bin src/Recursividad/*.java
   ```

2. **Ejecutar el programa principal:**
   ```bash
   java -cp bin Recursividad.Main
   ```
